# Course Study Materials - PDF Upload Instructions

## File Naming Convention

**Week-wise Notes:**
- `week-1-2-notes.pdf` (Week 1-2 notes)
- `week-3-4-notes.pdf` (Week 3-4 notes)
- etc...

**Additional Materials:**
- `cheat-sheet.pdf` (Complete Cheat Sheet)
- `practice-assignments.zip` (Practice Assignments)
- `reference-links.pdf` (Reference Links & Resources)

## How to Add PDFs:

1. **Full Stack Web Development ke liye:**
   - PDFs ko `frontend/public/course-materials/full-stack-web-development/` me add karo
   - File names exactly ye honge:
     - `week-1-2-notes.pdf`
     - `week-3-4-notes.pdf`
     - `week-5-6-notes.pdf`
     - `week-7-8-notes.pdf`
     - `week-9-10-notes.pdf`
     - `week-11-12-notes.pdf`
     - `cheat-sheet.pdf`
     - `practice-assignments.zip`
     - `reference-links.pdf`

2. **Baaki courses ke liye:**
   - Apne course folder me jaao
   - Same naming pattern follow karo

## Important Notes:

- File names **exactly same** hone chahiye (spelling aur case-sensitive)
- PDF files 10MB se kam honi chahiye (performance ke liye)
- ZIP files bhi 20MB se kam
- Files add karne ke baad code automatically detect kar lega

## Example:

Agar aap Full Stack course ka Week 1-2 notes add kar rahe ho:
1. PDF file ka naam rakho: `week-1-2-notes.pdf`
2. Copy karo: `frontend/public/course-materials/full-stack-web-development/` me
3. Done! Website automatically download button show karega
